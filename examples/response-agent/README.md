# Synthetic response-agent example

This directory is a **synthetic** FAQ assessment fixture for source CLI 0.3.0.
It is not a production knowledge base, not a real customer policy, and not
included in the npm `@augmentworks/cli@0.2.0` tarball.

`--assessment` is available from a built source checkout (`node dist/index.js`).
Published `@augmentworks/cli@0.2.0` does not include that flag.

```yaml
# augmentworks.assessment.yaml is synthetic test data only.
```
