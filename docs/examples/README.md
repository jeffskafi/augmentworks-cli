# Sample reports

These files were generated by the implemented `demo` command. They contain only
synthetic data.

Regenerate:

```bash
npm ci
npm run build
npm run generate:demo-examples
```

Volatile identifiers (`run_id`, timestamps, attempt ids) change every run.
`excerpt-normalized.json` is a labeled transform; the `failing/` and `passing/`
directories retain raw provenance from the generation command.

## Hosted CI (source 0.3.3)

`github-actions-hosted-source.yml` is a copy-pastable quoted hosted workflow
for this source build. It is not a published `0.3.2` pin and must not be
advertised as an unpublished npm version until that tarball is verified on
the registry.

`github-actions-hosted-gate.yml` adds a read-only `gate` after quoted
execution and `run wait` on the original run ID. It requires an explicit
`AUGMENTWORKS_BASELINE_ID`. It does not issue machine credentials, create
GitHub secrets, auto-promote a pin, or start a second billed assessment.
