# Sample reports

These files were generated by the implemented `demo` command. They contain only
synthetic data.

Regenerate:

```bash
npm ci
npm run build
npm run generate:demo-examples
```

Volatile identifiers (`run_id`, timestamps, attempt ids) change every run.
`excerpt-normalized.json` is a labeled transform; the `failing/` and `passing/`
directories retain raw provenance from the generation command.
